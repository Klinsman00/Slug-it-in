# Slug It In 

this game is a fun and trolling game based on Pokémon Slugterra and my friend. You can duel with the bot by shooting at each other. You need to control the player by using the WASD key to move around and dodge the projectile and at the same time u need to pick up the pokeball(ammo) by pressing the R key. You need to aim and shoot the enemy by aiming your cursor on them and press the left button key.
